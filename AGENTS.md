# AGENTS.md / Project Ruleset

<project_rules>
1. Always write TypeScript with strict type definitions and clean modular components.
2. Default to Tailwind CSS v4 for all styling with utility classes.
3. Ensure minimum 44px touch targets on mobile viewports for all buttons and interactive controls (A11y Touch Target Size).
4. Never omit keyboard focus rings or WCAG AA contrast standards.
5. Provide ARIA live regions for screen readers (`role="status"`, `role="alert"`).
6. Implement INP-optimized debounced inputs (useDebounce) for zero-lag 60,000 product search.
7. Use spring physics (`motion/react`) for smooth, tactile micro-interactions.
8. Maintain 100% data fidelity: preserve all Shopee Affiliate links, product fields, categories, and SQLite/CSV synchronization.
</project_rules>
